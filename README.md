# مترجم PDF فارسی (اندروید)

یک اپ اندرویدی ساده که فایل PDF را باز می‌کند، متن هر صفحه را استخراج می‌کند و
آن را به‌صورت خودکار به فارسی ترجمه می‌کند — کاملاً روی خود گوشی (بدون نیاز به
کلید API یا سرویس ابری پولی).

## این پروژه چطور کار می‌کند

- **انتخاب فایل:** با دکمه «انتخاب فایل PDF»، سیستم انتخاب‌گر فایل اندروید باز می‌شود.
- **استخراج متن:** با کتابخانه [PdfBox-Android](https://github.com/TomRoush/PdfBox-Android) متن هر صفحه استخراج می‌شود.
- **تشخیص زبان مبدا:** با ML Kit Language Identification زبان متن هر صفحه تشخیص داده می‌شود.
- **ترجمه:** با ML Kit Translation، متن به فارسی ترجمه می‌شود. مدل‌های ترجمه
  در اولین استفاده از هر زبان (چند مگابایت) دانلود می‌شوند و بعد از آن ترجمه
  آفلاین کار می‌کند.
- نتیجه (متن اصلی + ترجمه) برای هر صفحه به‌صورت جداگانه و به‌محض آماده شدن
  در لیست نمایش داده می‌شود («در لحظه»).

## محدودیت‌های مهم

- برای PDFهای **اسکن‌شده** (تصویر خام بدون لایه متنی)، متنی برای استخراج وجود
  ندارد؛ برای این حالت باید OCR (مثلاً ML Kit Text Recognition) هم اضافه شود
  که در این نسخه اولیه پیاده‌سازی نشده.
- فایل‌های PDF **رمزگذاری‌شده/محافظت‌شده با رمز عبور** پشتیبانی نمی‌شوند.
- برای اولین استفاده از هر زبان مبدا، اتصال اینترنت لازم است (دانلود مدل ML Kit).

## نحوه ساخت و اجرا

1. [Android Studio](https://developer.android.com/studio) (نسخه Koala یا جدیدتر) را نصب کنید.
2. پوشه `PdfTranslatorFa` را با گزینه **Open** در Android Studio باز کنید.
3. صبر کنید تا Gradle Sync به‌صورت خودکار انجام شود (نیاز به اینترنت دارد تا
   وابستگی‌ها از Google/Maven دانلود شوند).
4. یک دستگاه اندرویدی (نسخه ۷ / API 24 به بالا) یا شبیه‌ساز وصل کنید.
5. روی دکمه **Run ▶** کلیک کنید.

برای گرفتن فایل نصبی (APK):
```
Build → Build Bundle(s) / APK(s) → Build APK(s)
```

## ساختار پروژه

```
PdfTranslatorFa/
├── app/
│   ├── build.gradle.kts          # وابستگی‌ها (PdfBox-Android، ML Kit، Compose)
│   └── src/main/
│       ├── AndroidManifest.xml
│       └── java/com/example/pdftranslator/
│           ├── MainActivity.kt        # رابط کاربری (Jetpack Compose)
│           ├── PdfTextExtractor.kt    # استخراج متن از PDF
│           ├── TranslatorHelper.kt    # تشخیص زبان + ترجمه با ML Kit
│           └── PageContent.kt         # مدل داده هر صفحه
├── build.gradle.kts
└── settings.gradle.kts
```

## پیشنهاد برای ادامه توسعه

- افزودن OCR برای پشتیبانی از PDFهای اسکن‌شده.
- امکان انتخاب زبان مقصد به‌جای فارسی ثابت.
- نمایش PDF اصلی در کنار متن ترجمه‌شده (به‌صورت split-view).
- ذخیره خروجی ترجمه در یک فایل جدید (PDF یا متن).
